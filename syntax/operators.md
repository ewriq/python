# 1. Arithmetic Operators

| Operator | Name | Example | Result |
|---|---|---|---|
| `+` | Addition | `5 + 3` | `8` |
| `-` | Subtraction | `5 - 3` | `2` |
| `*` | Multiplication | `5 * 3` | `15` |
| `/` | Division | `5 / 2` | `2.5` |
| `//` | Floor Division | `5 // 2` | `2` |
| `%` | Modulo (Remainder) | `5 % 2` | `1` |
| `**` | Exponentiation | `5 ** 2` | `25` |

---

# 2. Assignment Operators

| Operator | Description | Example | Equivalent |
|---|---|---|---|
| `=` | Assignment | `x = 5` | - |
| `+=` | Add and assign | `x += 2` | `x = x + 2` |
| `-=` | Subtract and assign | `x -= 2` | `x = x - 2` |
| `*=` | Multiply and assign | `x *= 2` | `x = x * 2` |
| `/=` | Divide and assign | `x /= 2` | `x = x / 2` |
| `//=` | Floor divide and assign | `x //= 2` | `x = x // 2` |
| `%=` | Modulo and assign | `x %= 2` | `x = x % 2` |
| `**=` | Exponentiate and assign | `x **= 2` | `x = x ** 2` |
| `&=` | AND and assign | `x &= 2` | `x = x & 2` |
| `|=` | OR and assign | `x |= 2` | `x = x | 2` |
| `^=` | XOR and assign | `x ^= 2` | `x = x ^ 2` |
| `>>=` | Shift right and assign | `x >>= 2` | `x = x >> 2` |
| `<<=` | Shift left and assign | `x <<= 2` | `x = x << 2` |
| `:=` | Walrus (assignment expression) | `x := 10` | Assigns and uses a value |
