# 1. Aritmetik Operatörler

| Operatör | Adı | Örnek | Sonuç |
|---|---|---|---|
| `+` | Toplama | `5 + 3` | `8` |
| `-` | Çıkarma | `5 - 3` | `2` |
| `*` | Çarpma | `5 * 3` | `15` |
| `/` | Bölme | `5 / 2` | `2.5` |
| `//` | Tam Bölme | `5 // 2` | `2` |
| `%` | Mod (Kalan) | `5 % 2` | `1` |
| `**` | Üs Alma | `5 ** 2` | `25` |

---

# 2. Atama Operatörleri

| Operatör | Açıklama | Örnek | Eşdeğeri |
|---|---|---|---|
| `=` | Atama | `x = 5` | - |
| `+=` | Toplayarak ata | `x += 2` | `x = x + 2` |
| `-=` | Çıkartarak ata | `x -= 2` | `x = x - 2` |
| `*=` | Çarparak ata | `x *= 2` | `x = x * 2` |
| `/=` | Bölerek ata | `x /= 2` | `x = x / 2` |
| `//=` | Tam bölerek ata | `x //= 2` | `x = x // 2` |
| `%=` | Mod alarak ata | `x %= 2` | `x = x % 2` |
| `**=` | Üs alarak ata | `x **= 2` | `x = x ** 2` |
| `&=` | AND ata | `x &= 2` | `x = x & 2` |
| `|=` | OR ata | `x |= 2` | `x = x | 2` |
| `^=` | XOR ata | `x ^= 2` | `x = x ^ 2` |
| `>>=` | Sağa kaydırarak ata | `x >>= 2` | `x = x >> 2` |
| `<<=` | Sola kaydırarak ata | `x <<= 2` | `x = x << 2` |
| `:=` | Walrus (atama ifadesi) | `x := 10` | Değer atayıp kullanır |
