## 1. Assignment Statement

Assigns a value to a variable.

```python
x = 10
name = "Python"
```

---

## 2. Conditional Statement

Allows the program to make decisions.

```python
if x > 0:
    print("Positive")
elif x == 0:
    print("Zero")
else:
    print("Negative")
```

---

## 3. Match Statement

Matches a value.

```python
match command:
    case "start":
        print("Started")
    case "stop":
        print("Stopped")
```

---

## 4. Loop Statement

Used for repeated operations.

### For

```python
for item in liste:
    print(item)
```

### While

```python
while x < 10:
    x += 1
```

---

## 5. Function Statement

Defines a function.

```python
def add(a, b):
    return a + b
```

---

## 6. Class Statement

Defines a class.

```python
class User:
    pass
```

---

## 7. Import Statement

Adds a module.

```python
import math
```

or

```python
from math import pi
```

---

## 8. Exception Handling Statement

Catches errors.

```python
try:
    x = 10 / 0

except:
    print("Error")

finally:
    print("Finished")
```

---

## 9. Return Statement

Returns a value from a function.

```python
def square(x):
    return x * x
```

---

## 10. Control Flow Statement

Controls loop flow.

### break

Ends the loop.

```python
break
```

### continue

Moves to the next step.

```python
continue
```

### pass

Does nothing.

```python
pass
```

---
