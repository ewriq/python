## 1. Assignment Statement (Atama)

Değişkene değer atar.

```python
x = 10
name = "Python"
```

---

## 2. Conditional Statement (Koşul)

Programın karar vermesini sağlar.

```python
if x > 0:
    print("Pozitif")
elif x == 0:
    print("Sıfır")
else:
    print("Negatif")
```

---

## 3. Match Statement

Değer eşleştirme yapar.

```python
match command:
    case "start":
        print("Başladı")
    case "stop":
        print("Durdu")
```

---

## 4. Loop Statement (Döngü)

Tekrarlı işlemler için kullanılır.

### For

```python
for item in liste:
    print(item)
```

### While

```python
while x < 10:
    x += 1
```

---

## 5. Function Statement

Fonksiyon tanımlar.

```python
def add(a, b):
    return a + b
```

---

## 6. Class Statement

Sınıf tanımlar.

```python
class User:
    pass
```

---

## 7. Import Statement

Modül ekler.

```python
import math
```

veya

```python
from math import pi
```

---

## 8. Exception Handling Statement

Hata yakalama yapar.

```python
try:
    x = 10 / 0

except:
    print("Hata")

finally:
    print("Bitti")
```

---

## 9. Return Statement

Fonksiyondan değer döndürür.

```python
def square(x):
    return x * x
```

---

## 10. Control Flow Statement

Döngü akışını kontrol eder.

### break

Döngüyü bitirir.

```python
break
```

### continue

Sonraki adıma geçer.

```python
continue
```

### pass

Boş bırakır.

```python
pass
```
