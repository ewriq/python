## 1. Literal Expression

Doğrudan değerler.

```python
10
3.14
"Hello"
True
None
```

---

## 2. Arithmetic Expression

Matematik işlemleri.

```python
x + y
x * 2
x ** 2
```

---

## 3. Comparison Expression

Karşılaştırma yapar.

```python
x > 10
x == 5
x != 0
```

Sonuç:

```python
True / False
```

---

## 4. Logical Expression

Mantıksal işlemler.

```python
x > 0 and x < 10
```

Operatörler:

```python
and
or
not
```

---

## 5. Function Call Expression

Fonksiyon çağırma.

```python
len("Python")
```

---

## 6. Collection Expression

Veri yapısı oluşturur.

Liste:

```python
[1, 2, 3]
```

Tuple:

```python
(1, 2, 3)
```

Set:

```python
{1, 2, 3}
```

Dictionary:

```python
{"name": "Ali"}
```

---

## 7. Index Expression

Eleman erişimi.

```python
list[0]
```

---

## 8. Slice Expression

Parça alma.

```python
text[0:5]
```

---

## 9. Lambda Expression

Anonim fonksiyon.

```python
lambda x: x + 1
```

---

## 10. Conditional Expression

Tek satır if.

```python
"yes" if x > 0 else "no"
```

---

## 11. Assignment Expression

Walrus operatörü.

```python
(x := 10)
```

---
