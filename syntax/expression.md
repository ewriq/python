## 1. Literal Expression

Direct values.

```python
10
3.14
"Hello"
True
None
```

---

## 2. Arithmetic Expression

Mathematical operations.

```python
x + y
x * 2
x ** 2
```

---

## 3. Comparison Expression

Performs a comparison.

```python
x > 10
x == 5
x != 0
```

Result:

```python
True / False
```

---

## 4. Logical Expression

Logical operations.

```python
x > 0 and x < 10
```

Operators:

```python
and
or
not
```

---

## 5. Function Call Expression

Calls a function.

```python
len("Python")
```

---

## 6. Collection Expression

Creates a data structure.

List:

```python
[1, 2, 3]
```

Tuple:

```python
(1, 2, 3)
```

Set:

```python
{1, 2, 3}
```

Dictionary:

```python
{"name": "Ali"}
```

---

## 7. Index Expression

Accesses an element.

```python
list[0]
```

---

## 8. Slice Expression

Takes a slice.

```python
text[0:5]
```

---

## 9. Lambda Expression

Anonymous function.

```python
lambda x: x + 1
```

---

## 10. Conditional Expression

Single-line if.

```python
"yes" if x > 0 else "no"
```

---

## 11. Assignment Expression

Walrus operator.

```python
(x := 10)
```

---
