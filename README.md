# Python Examples

A collection of small Python examples covering core language concepts.

Run a Python example with:

```bash
python path/to/file.py
```

## Project structure

### Syntax

- `syntax/assign.py` - Variable assignment.
- `syntax/var.py` - Variables.
- `syntax/expression.md` - Expressions.
- `syntax/operators.md` - Operators.
- `syntax/statement.md` - Statements.

### Data types

- `data_types/all.py` - `int`, `float`, `str`, `bool`, `list`, `dict`,
  `set`, `tuple`, `None`, type checking, and type conversion.

### Memory

- `memory/address.md` - Object identity and `id()`.
- `memory/allocation.md` - Memory allocation.
- `memory/deallocation.md` - Releasing allocated memory.
- `memory/garbage_collection.md` - Automatic cleanup of unused objects.
- `memory/heap.md` - Heap memory.
- `memory/reference.md` - Object references.
- `memory/stack.md` - Call stack and temporary function data.

### Conditions

- `matching/if_else.py` - `if` and `else`.
- `matching/elif.py` - Multiple conditions with `elif`.
- `matching/switch_case.py` - `match` and `case`.

### Loops

- `loops/for.py` - `for` loops.
- `loops/while.py` - `while` loops.
- `loops/do_while.py` - Do-while behavior in Python.
- `loops/matrix.py` - Nested loops and matrices.

### Data structures

- `data_structures/list.py` - Lists.
- `data_structures/array.py` - Arrays.
- `data_structures/map.py` - Key-value maps.
- `data_structures/set.py` - Sets.
- `data_structures/slice.py` - Slicing.
- `data_structures/queue.py` - FIFO queues.
- `data_structures/stack.py` - LIFO stacks.

### Strings

- `strings/format.py` - String formatting.
- `strings/index.py` - String indexing.
- `strings/join.py` - Joining strings.
- `strings/len.py` - String length.
- `strings/regex.py` - Regular expressions.
- `strings/replace.py` - Replacing text.
- `strings/split.py` - Splitting strings.
- `strings/upper_lower.py` - Uppercase and lowercase conversion.

### Functions and OOP

- `functions/func.py` - Functions, parameters, and return values.
- `oop/class.py` - Class definitions.
- `oop/object.py` - Objects and instances.

### Input and output

- `io/input.py` - User input.
- `io/stdin.py` - Standard input.
- `io/stdout.py` - Standard output.
- `io/stderr.py` - Standard error output.
- `io/buffer.py` - Input/output buffers.

### Files

- `files/read.py` - Reading files.
- `files/write.py` - Writing files.
- `files/append.py` - Appending to files.
- `files/meta.py` - File metadata.
- `files/data.txt` - File operation example data.

### Error handling

- `errors/try_catch.py` - `try`, `except`, `else`, and `finally`.
- `errors/data.txt` - Error handling example data.

### Modules

- `modules/maths.py` - Reusable math functions.
- `modules/calculator.py` - Using the math module.
- `modules/get.py` - Importing values from a module.
- `modules/__pycache__/maths.cpython-314.pyc` - Generated bytecode cache.

### Serialization

- `serialization/json_test.py` - Reading and writing JSON.
- `serialization/csv_test.py` - Reading and writing CSV.
- `serialization/xml_test.py` - Working with XML.
- `serialization/data.csv` - CSV example data.
- `serialization/__pycache__/csv.cpython-314.pyc` - Generated bytecode cache.
- `serialization/__pycache__/json.cpython-314.pyc` - Generated bytecode cache.
- `serialization/__pycache__/xml.cpython-314.pyc` - Generated bytecode cache.

### Networking

- `networking/http/main.py` - HTTP example.
- `networking/tcp/server/main.py` - TCP server.
- `networking/tcp/client/main.py` - TCP client.

### Concurrency

- `concurrency/thread.py` - Threads.
- `concurrency/async.py` - Asynchronous functions.
- `concurrency/await.py` - Waiting for asynchronous operations.
- `concurrency/coroutine.py` - Coroutines.
- `concurrency/mutex.py` - Mutex locks.
- `concurrency/semaphore.py` - Semaphores.
- `concurrency/race_condition.py` - Race conditions.
- `concurrency/progress.py` - Tracking concurrent task progress.

### Repository files

- `.gitattributes` - Git file attributes.
- `README.md` - Project documentation.
